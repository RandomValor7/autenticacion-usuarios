## Descripción

Proyecto desarrollado con React y JavaScript utilizando Vite. Permite realizar el registro de usuarios y la autenticación mediante un nombre de usuario y una contraseña.

## Funcionalidades

- Registro de usuarios.
- Inicio de sesión.
- Validación de usuario y contraseña.
- Mensaje de éxito cuando la autenticación es correcta.
- Mensaje de error cuando las credenciales son incorrectas.
- Validación de campos obligatorios.
